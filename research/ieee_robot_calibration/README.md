# Socket-based kinematic calibration for the AI-VHRS FR3 — simulation study

Research package (simulation only) for the manuscript
**"Simulation-Based Evaluation of Two- and Three-Socket MUKCa Kinematic Calibration with Trajectory Pre-Compensation for a
Closed-Controller 6-DOF Cobot in Vietnamese Handwriting Reproduction"**
(`paper/AI_VHRS_IEEE_Paper.pdf`, IEEE conference two-column, 8 pages, draft — not submitted, not peer-reviewed).

> **Every accuracy number in this package is a simulation result.** No motion command was sent to the real FAIRINO FR3.
> The only real-robot data used are two read-only controller readings already stored in `robot_agent/runs/`, used to check
> that the nominal model matches what the controller reports. Physical accuracy is unknown until the procedures in
> `REAL_WORLD_VALIDATION_REQUIRED.md` are carried out.

## Headline results (simulation, 30 robots, mean ± SD)

* Identifiable rank of the 39-parameter model from socket data: **21/39** for every layout and tilt range.
* Aligned TCP RMSE: nominal 0.748 ± 0.260 mm → two-socket 0.109 ± 0.045 mm → triangular three-socket **0.044 ± 0.005 mm**
  (−60 % vs two-socket, 28/30 robots, Holm p = 5.2e-8). Collinear three-socket = two-socket (p = 0.78).
* Handwriting in-plane MAE: nominal + paper probing 0.796 mm → two-socket pre-comp 0.180 mm → three-socket pre-comp
  **0.150 mm** (oracle 0.141 mm). Shape error (after rigid 2-D fit) 0.037 → 0.010 mm.
